# Aditya Kalyan — Data Analyst Portfolio

A GitHub Pages-ready personal portfolio inspired by the structure and visual storytelling of modern data analyst portfolios.

## Files
- `index.html` — portfolio content
- `style.css` — responsive dark UI
- `script.js` — mobile navigation + scroll reveal
- `assets/` — add profile photo, resume and project images here

## Publish on GitHub Pages
1. Create a repository named `portfolio` (or any name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/root`, then Save.
6. Your portfolio will be available at the GitHub Pages URL shown by GitHub.

## Before publishing
Replace:
- `aditya.kalyan@example.com` with your real email.
- Add your `resume.pdf` inside `assets/`.
- Add your profile image if desired.
- Update any experience dates/details that need exact verification.
